# 11. UI 명세 — 대시보드 + 벡터 탐색기

## 기술 스택
- React (JSX), 다크 테마 (#0a0a0f 배경)
- 모노스페이스 폰트 (JetBrains Mono / SF Mono)
- 데이터: Oracle REST API 또는 WebSocket 폴링 (2초 간격)

## 구조
```
App
├── Header (시스템 상태 표시등, 네비게이션, TESTNET 뱃지)
├── 대시보드 탭
│   ├── 좌측: 포트폴리오 카드 + 거래 통계 + FRED 거시
│   └── 우측: 메인 차트 + 거래 내역 테이블
└── 벡터 탐색기 탭
    ├── 필터 바 (정렬, 라벨, 이벤트, 날짜/시간 검색)
    ├── 통계 요약 카드 (7개)
    ├── 스냅샷 목록 테이블 + 상세 패널 (좌/우 분할)
    └── 선택 시 하단에 컨텍스트 차트 펼침
```

## 대시보드 탭

### 포트폴리오 카드 (좌측 상단, 항상 표시)
- TESTNET / 실전 모드 뱃지
- 투입금 (USDT)
- 현재 가치 (큰 글씨)
- 미실현 손익 (금액 + 퍼센트, 색상으로 양/음 구분)
- **거래 진행 중이면 테두리가 주황색으로 변경**

### 거래 통계 (포트폴리오 아래)
- 거래 횟수, 승률, 누적 수수료, 평균 보유 시간 (2×2 그리드)

### FRED 거시 지표 (통계 아래)
- 8개 FRED 시리즈 값 표시
- 하단에 10Y-2Y 스프레드 + 레짐 판단 결과

### 메인 차트 (우측, 핵심)
**평상시 (거래 없음):**
- BTCUSDT 가격 차트 (파란색 라인)
- 과거 완료된 거래 마커: 매수 진입(B 초록), 매도 진입(S 빨강), 청산(○)
- 각 거래의 PnL 표시

**거래 진행 중 (L3에서 activeTrade 존재 시 자동 전환):**
- 차트 색상이 주황색으로 변경
- 현재가에 깜빡이는 라이브 점
- 진입 시점 수직 점선 + 진입가 수평 기준선
- 차트 아래 정보 바: 패턴 ID, 유사도, 진입가, 현재가, 실시간 PnL, SL/TP 라인
- **거래 청산 시 자동으로 평상시 모드 복귀**

### 거래 내역 테이블
- 컬럼: 시간, 심볼, 방향, 진입가, 청산가, 순PnL, 수수료, 유사도, 상태
- 거래 진행 중이면 최상단에 LIVE 행 (주황색 배경, 깜빡이는 LIVE 뱃지)
- 누적 PnL 표시

### 하단 지표 바 (6개)
- 시장 레짐, BTC 현재가(스파크라인), 활성 패턴 수, 오늘 스냅샷 수, 가동 시간, 뉴스 감성

## 벡터 탐색기 탭

### 필터 바
| 필터 | 타입 | 옵션 |
|------|------|------|
| 정렬 | select | 순수익 높은순 / 낮은순 / MFE/MAE순 / 유사도순 / 최신순 |
| 라벨 | select | 전체 / 매수적합 / 매도적합 / 관망 |
| 이벤트만 | checkbox | 체크 시 event_flags > 0만 표시 |
| 기간 시작 | date + time | 날짜/시간 직접 입력 |
| 기간 종료 | date + time | 날짜/시간 직접 입력 |

### 통계 요약 (7개 카드)
- 결과 수, 매수적합, 매도적합, 관망, 미라벨, 평균 순수익, 최고 순수익

### 스냅샷 목록 (좌측 70%)
- 컬럼: #, 시간, 가격, 라벨, 순수익, MFE, MAE, MFE/MAE 비율, 이벤트, 유사도
- 기본 정렬: 순수익 높은순 (수익 평가 좋은 것 먼저)
- 최대 80건 표시 (스크롤)
- **행 클릭 → 우측 상세 패널 + 하단 차트 동시 표시**

### 상세 패널 (우측 30%)
선택된 스냅샷의 상세 정보:
- 스냅샷 ID, 시간, 가격, 라벨 뱃지
- **상황 벡터 주요 피처**: spread, imbalance, vwap_dev, buy/sell, tps — 바 차트
- **결과 벡터** (라벨 있을 때): 순수익, MFE, MAE, MFE/MAE 비율
- 왕복 수수료 차감 표시
- 매칭 패턴 ID + 유사도 (있을 경우)
- 미라벨 시: 회전하는 대기 아이콘

### 하단 컨텍스트 차트 (스냅샷 선택 시 펼침)
**핵심 — 이전에 보여준 4단계 차트의 실제 구현**

선택한 스냅샷을 중심으로 ±35캔들 범위의 가격 차트:
- 선택 지점: 주황색 수직 점선 + 동심원 마커
- 주변 스냅샷: 라벨별 색상 점 (초록=매수, 빨강=매도, 회색=관망)
- 관측 윈도우: 선택지점 ~ +5분 구간에 배경색 (초록/빨강)
- MFE 라인: 초록 점선 (가격 수준에 맞춤)
- MAE 라인: 빨간 점선 (가격 수준에 맞춤)
- 상단 요약 바: 스냅샷 ID, 시간, 라벨, 순수익, MFE, MAE, 비율
- 하단 범례: 색상 설명

## 데이터 연동

### 대시보드 실시간 데이터
```
GET /api/dashboard
→ { portfolio, trades, active_trade, prices, metrics }

WebSocket /ws/live
→ { type: "price" | "trade_open" | "trade_close", data: {...} }
```

### 벡터 탐색기 데이터
```
GET /api/snapshots?sort=ret_desc&label=BUY_GOOD&from=2026-03-17T14:00&to=2026-03-17T15:00&event_only=true&limit=80
→ { snapshots: [...], stats: {...} }

GET /api/snapshots/{snap_id}/chart?window=35
→ { prices: [...], snaps_in_window: [...], mfe_price, mae_price }
```
